# Graphics Assets

A shared asset library for graphics programming and rendering projects.

This repository provides common assets for Vulkan, OpenGL, and other rendering projects.

## Directory Structure

| Directory | Description |
| :---: | :---: |
| `models/` | 3D models (glTF, OBJ, PLY, etc.) |
| `textures/` | Textures (PNG, JPG, HDR, etc.) |

## Usage

This repository is designed to be used as a Git submodule by other graphics projects.
